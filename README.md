🎣 Tangkap Ikan - Game Seru Sederhana

Selamat datang di Tangkap Ikan, game kasual berbasis web di mana Anda harus menangkap ikan yang jatuh menggunakan ember. Semakin banyak ikan tertangkap, semakin tinggi skor dan gelar Anda! Game ini dirancang dengan tampilan menarik dan kontrol mudah — cocok untuk mengisi waktu luang.

🎮 Cara Bermain

· Tujuan: Tangkap ikan sebanyak mungkin sebelum waktu habis.
· Kontrol: Gunakan tombol ← (kiri) dan → (kanan) di pojok layar untuk menggerakkan ember.
· Skor: Setiap ikan yang tertangkap menambah 1 poin.
· Waktu: Anda memiliki waktu 60 detik. Kejar skor setinggi mungkin!
· Level/Gelar:
  · 0–10  : Pemula
  · 11–30 : Biasa
  · 31–50 : Junior Mancing
  · 51–70 : Senior Mancing
  · 70   : Dewa Mancing
· Game Over: Ketika waktu mencapai 0, permainan berhenti dan skor akhir ditampilkan.
· Ulangi: Klik tombol 🔄 Ulang untuk memulai permainan baru.

✨ Fitur Utama

· Tampilan visual menarik dengan latar air, ombak, ember, dan ikan bergaya kartun.
· Kontrol responsif – tombol dapat digunakan dengan klik mouse atau sentuhan (touch) di perangkat mobile.
· Sistem level dinamis yang berubah sesuai skor.
· Timer menegangkan (60 detik) yang membuat permainan semakin seru.
· Animasi ikan jatuh dan tabrakan dengan ember.
· Game over screen dengan skor akhir dan gelar yang diraih.

🛠️ Teknologi yang Digunakan

· HTML5 Canvas – untuk rendering grafis game.
· CSS3 – styling antarmuka dan tombol.
· JavaScript (ES6) – logika permainan, deteksi tabrakan, timer, dan kontrol.

🚀 Cara Menjalankan

1. Salin kode dari file HTML ke dalam editor teks (misalnya Notepad, VS Code).
2. Simpan dengan nama index.html (atau nama lain berekstensi .html).
3. Buka file tersebut menggunakan browser web modern (Chrome, Firefox, Edge, dll).
4. Mainkan langsung! Tidak perlu instalasi tambahan atau koneksi internet (kecuali untuk mengunduh file).
